# Distributed Calculations (C) — учебный проект

Реализация минимальной библиотеки и примеров «Управляющий узел / Рабочий узел»
для распределённых вычислений табличного интеграла. Соответствует требованиям
1–6, 7.2 и 7.5 практикума.

## Быстрый старт (на одной машине)

```bash
make          # сборка (по умолчанию gcc, см. переменную CC)
# в одном терминале
./bin/manager 2 127.0.0.1 5555 --a 0 --b 1 --n 100000 --timeout 20
# в двух других терминалах (или в фоне)
./bin/worker --host 127.0.0.1 --port 5555 --cores 2 --timeout 20
./bin/worker --host 127.0.0.1 --port 5555 --cores 2 --timeout 20
```

Менеджер распределит подзадачи по рабочим узлам, соберёт результаты и выведет
значение интеграла, а также время выполнения.

## Автотесты

```bash
make test
```

Скрипт `scripts/test.sh` автоматически поднимает кластер на localhost и проверяет:
- корректность результата интегрирования;
- обратную пропорциональность времени суммарному числу ядер (грубая проверка);
- реакцию на отказ рабочего узла.

Логи тестов сохраняются в `tests/out`.

## Проверка на масштабируемость

```bash
make bench
```

Запускает пример на разных конфигурациях и выводит результат в виде таблицы.

## Сборка разными компиляторами и флаги безопасности (7.5)

Поддерживаются gcc/clang. Можно выбрать компилятор:

```bash
make clean && make CC=clang
make clean && make CC=gcc
```

## Что реализовано

- Простая текстовая протокол-линия поверх TCP (newline-delimited).
- «Управляющий» принимает заданное число рабочих, раздаёт им подотрезки, ждёт
  результаты либо таймаут/отказ, в случае критики — завершает все узлы с ошибкой.
- «Рабочий» ограничивает число потоков (ядра) и общее время выполнения.
- Численный интеграл методом трапеций с делением на чанки.

## Структура

- `include/distr.h` — API библиотеки.
- `src/*.c` — реализация.
- `manager.c`, `worker.c` — пример использования.
- `scripts/test.sh` — автоматические сценарии (make test).
